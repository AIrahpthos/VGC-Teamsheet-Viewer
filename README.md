# VGC Teamsheet Viewer

An iPad-friendly viewer for public Pokémon VGC teamsheets from RK9.

## Use

1. Select a tournament.
2. Search for a player.
3. Open their published teamsheet.

The six Pokémon are displayed together in a compact layout designed for use during tournaments.

## Features

- Searches public RK9 tournament rosters
- Displays published teamsheets by player
- Supports Scarlet/Violet Tera-type sheets and Champions sheets
- Responsive layout for iPad, phones and desktop
- No RK9 account or login required

## Notes

Only publicly available RK9 data is displayed. Unpublished teamsheets cannot be viewed.

This is an unofficial viewer and is not affiliated with RK9, Pokémon, Nintendo, Game Freak or The Pokémon Company.
